# Brew & Bean Café

A professional multi-page café website built with HTML5, CSS3, and vanilla JavaScript.

## Project Structure

```
brew_bean_cafe/
├── index.html
├── about.html
├── menu.html
├── gallery.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md
```

## Features

- Clean and professional design
- Coffee brown, beige, and cream color theme
- Responsive navigation across all pages
- Beginner-friendly code structure
- No external dependencies or packages

## Pages

- **Home** (index.html) - Welcome page
- **About** (about.html) - Café story and information
- **Menu** (menu.html) - Coffee and food offerings
- **Gallery** (gallery.html) - Photo gallery
- **Contact** (contact.html) - Contact information

## How to Run

1. Open the project folder in your code editor.
2. Open `index.html` in your web browser.
3. Navigate between pages using the top navigation bar.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
